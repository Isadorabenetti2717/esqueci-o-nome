Por que AES-GCM?

AES é um padrão de criptografia simétrica amplamente utilizado. O modo GCM, além de esconder o conteúdo, verifica se os dados foram alterados. Nesta demonstração, a Web Crypto API faz todo o trabalho com segurança e desempenho nativos do navegador.
